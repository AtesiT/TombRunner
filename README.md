# TombRunner

Прототип веб-игры в стиле Tomb Raider (окружение + физика), сделанный на [Three.js](https://threejs.org/).

## Что есть в прототипе
- Персонаж от третьего лица с анимацией хода, бегом (Shift) и прыжком (Пробел).
- Собственная физика: гравитация, скольжение по стенам, опора о пол/платформы, подъём по ступенькам, нельзя пробить головой потолок.
- Камера за спиной с коллизией — не заходит в стены.
- Уровень в стиле древнего храма: пол, центральная яма (смерть + респавн), стены, колонны, две платформы с лестницами.
- 3 собираемых золотых артефакта; после сбора всех — прототип считается пройденным.
- Управление: WASD + мышь (pointer lock) на десктопе; виртуальный джойстик + кнопки действия + тач-оглядка на мобайле.

## Запуск локально
```bash
npm install        # один раз (установит three)
npm start          # или просто откройте index.html в браузере
```
Любой статический сервер подойдёт, например `python3 -m http.server 8080` и откройте `http://localhost:8080`.
